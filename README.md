# Roblox Animal Collection Game

Animal Brainrot Adventure is a Roblox animal collection game script featuring a generated meadow island, custom animal models, proximity prompts, coin rewards, creature respawns, leaderstats, and a live collection HUD. The world and creature models are built from Roblox Parts at runtime.

## Install

1. Open your experience in Roblox Studio.
2. Create a Script in `ServerScriptService` named `BrainrotGame.server.lua` and paste in the server script from this project.
3. Create a LocalScript in `StarterPlayer > StarterPlayerScripts` named `BrainrotHUD.client.lua` and paste in the client script.
4. Press Play to test. The server script creates the island and creatures in `Workspace > AnimalBrainrotWorld`.

## Use

1. Walk from the spawn plaza toward one of the animals.
2. Approach it and hold the `Collect` prompt to earn coins.
3. Check the HUD for your coin balance and total collected creatures.
4. Wait 12 seconds for a collected creature to respawn.
